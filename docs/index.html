Why this exists

Committers.top ranked ebrahimHakimuddin #2 on Tanzania's board for a repo whose own README claims it doesn't create real commits — it does: ~137,000 of them, messages literally reading "commit 5000," "commit 4999," all landing in the same second. Raw counts alone can't catch that. This page pulls real numbers directly from GitHub instead of relying on a third-party scraper that can go stale for weeks without anyone noticing.

Built on api.github.com/graphql directly, not scraped. Updates every 5 days via a self-hosted cron job.
